## 👨‍💻 About Me

Hi, I'm **Suraj Khanderao**, a DevOps Engineer with **3.5+ years of experience** working with cloud infrastructure, Kubernetes, CI/CD automation, and Infrastructure as Code.

I enjoy building reliable cloud-native environments, automating application delivery, and improving deployment workflows through DevOps and GitOps practices.

- ☁️ Working with **AWS**, especially Amazon EKS, EC2, VPC, IAM, ECR, RDS, S3, and CloudWatch.
- ☸️ Managing containerized workloads with **Docker, Kubernetes, Helm, and Amazon EKS**.
- ⚙️ Automating build and release workflows using **Jenkins, GitLab CI/CD, and GitHub Actions**.
- 🔁 Implementing GitOps-based delivery with **Argo CD** and Git-managed Kubernetes manifests.
- 🏗️ Automating infrastructure with **Terraform and Ansible**.
- 🔐 Applying DevSecOps practices with **SonarQube, Trivy, Gitleaks, AWS Secrets Manager, and HashiCorp Vault**.
- 📊 Working with **Prometheus, Grafana, CloudWatch, and EFK/ELK** for monitoring and observability.
- 🎯 Interested in AWS DevOps, Kubernetes, platform engineering, automation, and cloud-native operations.

**Open to:** DevOps Engineer | AWS Cloud Engineer | Kubernetes / Platform Engineering opportunities.
